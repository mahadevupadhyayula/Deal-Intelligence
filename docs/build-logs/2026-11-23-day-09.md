### Finding from the live test (fixed)
The first smoke run failed step 7: stopping a worker left its in-flight job in `running` forever. ARQ cancels the running job on SIGTERM (no drain), and the row was never updated; stranded `running` rows count toward the tenant's active-job cap, so repeated deploys would eventually lock a tenant out. `run_job` now records a cancelled job as `failed: worker stopped before the job finished; resubmit` (provider usage still flushed) and re-raises. Verified by a unit test and by smoke step 7.

## 2. What it achieves
The whole Slice 1 stack starts with one command on any machine, with least-privilege secret wiring, a verified health and startup model, and evidence that tenant isolation, queueing and scale-out behave inside containers, not only in tests. It is the validated image and environment contract that Kubernetes (010) and Terraform (011) will reuse.
