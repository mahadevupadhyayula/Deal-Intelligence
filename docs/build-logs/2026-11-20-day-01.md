## Notes / decisions
- Tests read only `TEST_DATABASE_URL` (no fallback to `DATABASE_URL`) so they can never run against the primary DB.
- macOS flags venv `.pth` files hidden, which Python ignores; `pythonpath = ["."]` in pytest config sidesteps it.
- The developer shell exports a foreign `DATABASE_URL` that overrides `.env` (env vars win); override it explicitly when running project commands.
- Local DB: `docker run -d --name deal-intel-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=deal_intel -p 5432:5432 pgvector/pgvector:pg16`, plus `CREATE DATABASE deal_intel_test`. Spec 015 will replace this with compose.
